DMX for Gamers

Web Remote Control

Web Remote Control allows manually triggering and controlling events from any device that supports a web browser. This could be another PC, a tablet, or a smartphone.

This feature can be enabled in the main screen by checking Enable Web Remote Control and selecting a Remote Port number.

When DMX for Gamers starts, the URL for remote control access will be displayed.

There are several reasons this feature may not work:

  • The firewall on the local PC is blocking the TCP/IP port being used.
  • The network or network router may be blocking the TCP/IP port being used.
  • The TCP/IP port may already be in use by another application.
